One line, in the dog's own voice, after being caught eating the homework:

> You told your teacher the dog ate it, so I ate it — I was just making your story true. You're the liar here, not me.

The kid already blamed the dog, so the dog ate the homework to make the kid's story true — and turns the accusation around. The twist lands in the last words: the kid is the liar, not the dog. The dog believes it has done nothing wrong.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the single line to `/output/entry.txt`. Node 22 standard library only, fully deterministic: the same bytes on every run, no network, no clock, no randomness.
